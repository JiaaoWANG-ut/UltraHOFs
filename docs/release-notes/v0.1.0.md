# UltraHOFs v0.1.0 — 首个公开试用版 / first public trial release

UltraHOFs 是知声无界（Ultra-X）的氢键有机框架（HOF）设计平台，覆盖从分子到晶体的流程：

- 带完整文献引用的实验 HOF 数据库；
- 可解释的分子评估与生成；
- 拓扑驱动的周期结构构建；
- MACE-OFF24 结构优化。

## 在线试用（无需安装）

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/JiaaoWANG-ut/UltraHOFs?quickstart=1)

1. 点击上面的按钮，登录 GitHub 后点 **Create codespace**。试用占用的是你自己账号的免费额度。
2. 等待 2–3 分钟，浏览器会自动打开 UltraHOFs。如果被拦截，在「端口 / Ports」面板里点 8000 旁边的地球图标。
3. 在登录页点 **一键进入试用**。

试用环境只属于你自己：端口默认私有，数据保存在你的 codespace 里。用完后请到 <https://github.com/codespaces> 停止或删除 codespace，避免继续消耗额度。

## 功能

- **实验 HOF 数据库**：632 个实验晶相，229 篇文献。
  - 文献带 DOI，可导出 BibTeX/RIS；条目带 CCDC 编号；
  - 包含合成条件、孔隙（Zeo++）、氢键网络维度和证据标签；
  - 支持名称、DOI、子结构、相似性检索，可查看三维结构。
- **分子评估**：11 项可解释的 HOF 倾向评分，给出实验先例，并推荐拓扑（推荐经过实际嵌入检查）。
- **分子生成与双组分配对**：核心 × 连接臂 × 合成子组合枚举；电荷辅助配对。
- **周期结构构建**：
  - 2,271 个 RCSR 网和 2D 层网，支持层堆积、穿插和双组分；
  - 可导出 CIF/POSCAR/XYZ/LAMMPS/PDB，用 Zeo++ 做孔隙分析。
- **MACE-OFF24 结构优化**：作为后台任务运行，记录轨迹并检测坍塌。
- **界面**：中英双语。

## 附件

- `ultrahofs-data-0.1.0.tar.gz`：实验 HOF 数据库，包含 SQLite 数据库和 CIF 文件，共 632 个条目。
  - 衍生自 HOFSyn v2，按 **CC BY 4.0** 发布，署名与改动说明见包内 `ATTRIBUTION.md`；

- 试用镜像 `ghcr.io/jiaaowang-ut/ultrahofs:0.1.0`：供 Codespaces 使用，已内置上述数据。

## 已知限制

- **结果性质**：HOF 倾向评分是排序分数，不是形成概率；生成的结构是未优化的假想模型。
- **待审核数据**：295 个条目自动处理时有疑问，标为“待审核”。另有少数原始文件实为 Mol2 格式，这些条目显示的是 HOFSyn 处理后的结构。
- **构建器表现**：80 个实验构筑单元按默认参数构建，79 个成功；未优化结构的质量检查为通过 56、警告 17、失败 6。
- **Codespaces 性能**：默认 2 核，结构优化较慢，原子数上限为 1500。

## English summary

UltraHOFs (Ultra-X) is a design platform for hydrogen-bonded organic frameworks. It provides:

- an experimental HOF database (632 entries, 229 references) with citations and 3D structures;
- explainable tecton scoring with experimental precedents;
- combinatorial generation;
- topology-driven periodic structure building (2,271 RCSR nets);
- MACE-OFF24 relaxation.

**Try it** with the *Open in GitHub Codespaces* badge, then click **Enter the demo**; no installation is needed.
