# UltraHOFs 使用指南 / User guide

> 不想安装？用 GitHub Codespaces 在线试用：见 [README 的「在线试用」](../README.md#在线试用无需安装-try-it-online)，打开后在登录页点 **一键进入试用**。

## 1. 实验数据库 · Experimental database

- **检索**：左侧可按名称、DOI、作者、CCDC 编号检索，并可按合成子、氢键类型、拓扑、年份、氢键网络维度、几何孔隙、电荷辅助筛选。
- **结构检索**：可按子结构（SMARTS 或 SMILES）、相似性或精确匹配检索，结构可直接绘制（Ketcher）。
- **条目页**分为以下几部分：
  - 组分：tecton / co-tecton / 反离子，附配比和评分；
  - 证据标签：已报道晶体结构 / 延伸氢键网络 / 几何孔隙 / 活化后保持 / 实测孔隙，每项注明“计算 / 审核 / 文献”来源；
  - 引用：ACS 格式和 DOI，可下载 BibTeX/RIS，并提供 CCDC 链接；
  - 晶胞与孔隙（去客体框架，Zeo++）；
  - 三维结构（超胞，氢键以金色虚线显示）；
  - 合成条件。
- **审核状态**：`自动收录` 表示高置信度自动导入；`待审核` 表示自动处理有疑问（例如缺氢、无序、含金属、Mol2 文件），需由 curator 核对。

## 2. 分子评估 · Evaluate

输入 SMILES 或绘制分子后，会得到以下结果：

1. **HOF 倾向评分**（0–100），以雷达图展示 11 项构成，每项附解释。总分 = 加权和 × 关键门控（连接数、刚性）。**这是排序分数，不是形成概率。**
2. 在实验构筑单元中的百分位。
3. **实验先例**，分为四级：同一分子；不同质子化态或互变体；同骨架；未报道但有相似分子。每一级都附条目、CCDC 和 DOI。
4. **推荐拓扑**：分两步。
   - 先把合成子配对中心的连接方向与 RCSR 网、2D 层网的节点做 RMSD 匹配；
   - 再对候选网做一次实际嵌入，检查三项：配对的合成子能否正对（夹角 ∠ ≤ 15°）、连接点能否闭合（ΔX ≤ 0.3 Å）、分子是否重叠。不满足的网标为“匹配差”并降低排序。

   有 HOF 先例的网带 HOF 标记。点“构建结构”即可进入构建器。

## 3. 分子生成 · Generate

选择核心（按连接数和几何分组）、连接臂和合成子后，平台会按以下方式处理：

- 对称枚举并去重，然后打分排序；
- 每个候选附合成路线提示（基于模板，并非经过实验验证）；
- 若候选已在数据库中有实验报道，会标为“已报道”；
- 数量较大的请求自动转为后台任务。

## 4. 双组分 · Two-component

阳离子构筑单元（脒鎓、胍鎓、铵）与阴离子构筑单元（羧酸根、磺酸根、膦酸根）配对，平台给出：

- 电荷平衡配比；
- 合成子互补性，例如脒鎓–羧酸根的 R2²(8) 盐桥、GS 层；
- 拓扑兼容性（dia、hcb/srs、sql、tbo/pto 等）。

结果可以一键送入构建器的双组分模式。

## 5. 结构构建 · Builder

| 模式 | 用途 |
|---|---|
| 单组分 | 每个网节点放一个构筑单元，合成子在边中点配对 |
| 单组分 + 线性连接体 | 2 连接的分子放在每条边上，如四脒鎓 + 对苯二甲酸根 → dia |
| 双组分（同连接数） | 二部着色网，A/B 交替排列，如三脒鎓 + 均苯三甲酸根 → hcb |
| 双组分（不同连接数） | RCSR 双节点网，如 3,4-c 的 tbo、ctn |

参数说明：
- **2D 网**：堆积方式（AA 重叠成孔道 / AB / ABC）、层间距（自动值 = max(3.4 Å, 层厚 + 3.2 Å)）、滑移量；
- **3D 网**：穿插重数（1–6，自动搜索穿插平移矢量）；
- **合成子扭转对齐**：转动端基合成子，使相邻合成子形成 D–H···A 配对。

**质量检查**项目：分子间近距离接触、氢键数/分子、氢键网络维度是否达到网络维度、密度、连接点偏差、合成子配对夹角（超过 30° 会给出警告并建议换网）。随后可以：
- 用 Zeo++ 计算孔隙（PLD、LCD、N₂ 可及比表面、孔隙率、通道维度）；
- 导出 CIF（P1 或对称化）/ POSCAR / extXYZ / LAMMPS / PDB；
- 提交 **MACE-OFF24** 优化。优化先固定晶胞优化原子，再优化晶胞；完成后生成新的“已优化”结构，记录能量与体积变化、坍塌标记和轨迹。

## 6. 任务 · 项目 · 管理

- **任务中心**：查看进度、日志和结果链接，可取消任务。登录节点上为 CPU 模式，优化的原子数上限为 1500。
- **项目**：可收藏分子、结构和数据库条目。
- **管理后台**（curator/admin）：
  - 审核队列：通过或拒绝条目；
  - 新增条目：输入 DOI 自动获取文献信息，录入组分、条件、证据标签，并上传 CIF（自动分析）；
  - 用户与角色管理；
  - CSD 连接器状态。

## 7. 方法说明 · Methods notes

- **CIF → SMILES**：用 gemmi 读取并保留主无序组分，经周期成键分析拆分出分子，再用价态缺口加最大匹配法确定键级与形式电荷，并检查晶胞电荷是否平衡（不平衡说明可能缺氢）。按角色区分 tecton、co-tecton、反离子、溶剂和客体。
- **合成子连接点 X**：对中心对称的 R2²(n) 二聚体，X = M(D,A) + d/2·n̂（例如 COOH 二聚体的 O···O 距离取 2.64 Å）；电荷辅助配对和轴向基团沿成键轴方向放置。
- **组装**：先按“边长 = 两端半径之和”做最小二乘缩放，再交替进行 Kabsch 节点取向和“节点位置 + 晶胞矩阵”联合线性最小二乘，使配对的 X 点重合，最后对合成子扭转做网格搜索。扭转搜索的目标是 D–H···A 配对，同时惩罚 H···H、H···X 和重原子之间的近距离接触，避免两个 O–H 正对的错误构型。
